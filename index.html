คำถามที่พบบ่อย

เติมเกมใช้เวลานานไหม?

ระบบออกแบบให้รองรับการทำรายการอย่างรวดเร็ว โดยระยะเวลาจริงจะขึ้นกับบริการและผู้ให้บริการ API ที่เชื่อมต่อในระบบหลังบ้าน

ถ้าเติมแล้วไม่เข้า ต้องทำอย่างไร?

เก็บเลขคำสั่งซื้อไว้ แล้วติดต่อแอดมินผ่านช่องทางติดต่อด้านบน ทีมงานจะตรวจสอบสถานะรายการให้

สามารถตรวจสอบประวัติการเติมได้หรือไม่?

ได้ เมื่อระบบสมาชิกและฐานข้อมูลถูกเชื่อมต่อในชุดถัดไป ลูกค้าจะดูประวัติรายการและสถานะคำสั่งซื้อได้จากบัญชีของตนเอง
